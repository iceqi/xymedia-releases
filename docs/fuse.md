# 本地媒体 FUSE

FUSE 是可选的宿主机媒体挂载模式。需要 Linux 主机存在 `/dev/fuse`，管理员以 root 运行维护菜单，并使用已存在、绝对路径、非符号链接的目录。首次配置时目标目录必须为空，且不能是其他应用正在读写的普通数据目录。

在安装器菜单 `5` 中：

1. 选择“一键挂载本地媒体库”，按提示填写宿主机目录并确认。
2. 选择“启动/重启已配置挂载”可重新使用已保存路径。
3. 选择“停用本地媒体库挂载”可停止受管理挂载并恢复普通应用模式。

启用时应用容器需要 `/dev/fuse` 和 `SYS_ADMIN`，安装器会使用公开的 FUSE Compose 覆盖配置。挂载动作只需管理员执行；媒体服务能否读取内容仍取决于目录映射和容器用户权限。

如果路径是符号链接、不是空目录、挂载不是本实例管理的挂载，安装器会拒绝操作。失败时先查看菜单诊断和 `docker logs --tail=200 xymedia-app`；不要为排障公开 secrets 或完整 `.env`。
