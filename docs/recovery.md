# 用户恢复指南

恢复前停止应用，保留当前安装目录、失败后的 release 和原备份；不要先执行清理菜单，也不要用会删除数据卷的命令代替恢复流程。

## 基本步骤

1. 记录操作前的安装目录、版本、端口和 `docker ps --filter name=xymedia` 输出。
2. 备份当前 `.env`、`secrets/`、`data/`、`components/`、`releases/` 和小雅数据。
3. 若新版本未通过 `/api/health`，停止新应用，保留失败目录和日志。
4. 从已验证备份恢复到安装目录对应位置，检查目录归属和权限。
5. 重新运行公开安装器，确认保留现有配置，再启动并等待健康检查。

数据库恢复必须使用与备份相符的工具和版本，并先在副本上验证；不要覆盖唯一备份，也不要覆盖 secrets 或用户媒体目录。外部 PostgreSQL、跨主机迁移或数据库大版本迁移需要按数据库管理员的独立流程执行，本安装器不会替你猜测卷或删除源数据。

恢复成功后确认登录、控制器健康、WebDAV、TVBox、组件状态和媒体访问。只有确认新实例稳定后，才可清理失败副本。
